# Sample data

Nothing in this folder comes from the internet-facing sensor.

| Folder | What it is |
|---|---|
| `synthetic/` | Generated by `tools/generate_sample_logs.py` (seed 1337). Source addresses are random global unicast IPs, **not observed attackers**; payload hashes are SHA-256 of placeholder strings; download URLs use RFC 5737 documentation addresses and `.invalid` domains. |
| `local-cowrie/` | Real Cowrie 3.1.4 output on a development machine, driven by `tools/simulate_attacks.py` against 127.0.0.1. The sensor hostname and UUID (which embeds a MAC address) are scrubbed. |

Each folder has the raw log and the `stats.json` the collector makes from it.
